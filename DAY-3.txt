Add the following columns to the table:
 emp_id, age, experience, gender, emp_name, address, salary, department, skills, joining_date.
Use INT datatype for emp_id.
Use TINYINT datatype for age.
Use SMALLINT datatype for experience.
Use CHAR(1) datatype for gender.
Use VARCHAR(50) datatype for emp_name.
Use TINYTEXT datatype for address.
Use DECIMAL(10,2) datatype for salary.
Use ENUM('HR','IT','Sales','Finance','Support') datatype for the department.
Use SET('Java','Python','SQL','Excel','Communication') datatype for skills.
Use DATE datatype for joining_date.
Make emp_id as PRIMARY KEY.
Display the structure of the table after creation.
Show all tables available in the database.

CREATE TABLE company_staff (
    emp_id INT primary key ,
    age TINYINT,
    experience SMALLINT,
    gender CHAR(1),
    emp_name VARCHAR(50),
    address TINYTEXT,
    salary DECIMAL(10,2),
    department ENUM('HR','IT','Sales','Finance','Support'),
    skills SET('Java','Python','SQL','Excel','Communication'),
    joining_date DATE
);
